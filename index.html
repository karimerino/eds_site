EDS 124BR / LOOPS

Breakdancer Sprite

Using repeats to create movement, rotation, and a complete animated routine in SNAP!

For this assignment, I created a breakdancer animation where Sprite performs a complete routine using repeated blocks. Sprite moves across the screen, spins in place, says "Nailed it!", moves back, shrinks, and then says goodbye.

The code works by using repeats to control different parts of the animation. One repeat loops 4 times to move Sprite to the right, while another loops 4 times to move Sprite back to the left. The program also uses repeats to control the spin rotation with 10 turns and to gradually shrink Sprite over 5 loops.

If I changed the spin repeat from 10 repeats to 20 repeats, Sprite would spin twice as many times in place before continuing to the next part of the routine.
